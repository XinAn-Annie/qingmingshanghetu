# 动效复刻清单

## 进入页面

1. `JSstart/imgPreload.js` 预加载首屏图像，更新进度指针。
2. 预加载结束后显示开始按钮；点击后播放 `video/openVideo_landscape_720p_60fps_v001.m4v`，音量按钮切换静音，`Skip` 跳过开场。
3. 开场结束或跳过后显示顶部主题导航和 Nature 首屏。

## Nature（境）

- 首屏把山水、湖面、树枝、人物、游船/飞鸟和标题拆成多层，使用绝对定位、GIF 和滚动进度改变透明度、位移与缩放。
- 第二屏使用视频背景和浮动文字，进入/离开屏幕时由滚动事件控制播放、暂停和文字显隐。
- 第三屏是《溪山行旅图》探索段：画卷、卷轴边、放大镜、标尺、远中近景和注释层随滚动逐段出现，局部交互可打开解读弹层。
- 第四屏是《早春图》展开段：画面卷轴、快门/取景框、山体层和注释卡片按滚动进度展开，插入视频与局部放大交互。
- 末尾是 Nature 的画作/专家内容卡片，使用 Swiper 切换，并支持 Insight/Gallery 入口。

公共预加载和视口适配位于 `JSstart/imgPreload.js` 与 `JSgroup/index.js`；当前入口只加载 `JSgroup/areajs.js`，不会再初始化其他主题。
