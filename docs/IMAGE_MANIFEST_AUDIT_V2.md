## 2026-11-08 逐层复核补充

截图中接触表的许多“很小”图层是全画布坐标掩膜，缩略图小不代表缺失；真正的问题是页面把不同裁切坐标的掩膜重复拉伸、平移叠加，形成屋顶和桥洞重影。

已完成：

- 活动页面图层从 53 个引用收敛为 27 个有效图层，全部存在且可读取。
- 删除错位的 1024×1024 氛围/墨线叠加层、重复人物/货物/前景层和代理底图层。
- 虹桥层统一转换到 `img3_8.jpg` 的 `[0,430,3080,1749)` 坐标画布：桥上人群、桥洞结构、桥下船只均为同源对齐 PNG。
- 禁止 JavaScript 对同一源坐标掩膜做逐层平移和缩放，避免重影。
- 逐层审计记录：`MATERIAL_AUDIT_20261108.json`。

网关 `/v1/models` 当前没有 `image2.5`，仅有 `qwen-image-2.0` / `qwen-image-3.0-pro` 图像模型。由于本次复核确认原始实例素材完整，为保持清院本画风，没有将不稳定的独立生成对象混入页面；缺失内容由同源原图和对齐实例层补足。
- 裁切透明边界后的逐层接触表：`MATERIAL_AUDIT_CROPPED_CONTACT.jpg`；它显示实际对象，而不是把全画布掩膜缩成一个小点。
